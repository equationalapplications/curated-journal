# night-shift-seed

Generated by `npm run seed:night-shift`: 50 journal notes (~500 words each, 3 cross-links per note) as an OKF bundle.

Do not edit by hand; regenerate instead.

## Get the zip onto a device

- **Android emulator / USB device:** `adb push fixtures/night-shift-seed.zip /sdcard/Download/`
- **iOS simulator:** drag `fixtures/night-shift-seed.zip` onto the simulator window; it lands in Files.
- **Physical iPhone:** AirDrop the zip, then choose "Save to Files".

Then in the app: **Settings → Import OKF → pick `night-shift-seed.zip`**.
